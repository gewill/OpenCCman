# Mac basic text-size matrix, three languages and two themes (#191 / #57)

On 2026-09-25, the basic workspace was exercised in **1024×768 pt** and **300×412 pt** windows, with English, Simplified Chinese, and Traditional Chinese UI; Light and Dark app appearances; and the app's 100%, 125%, and 150% text-size choices. That is 36 *basic workspace states*. In every group, the selected size was read back from the Settings accessibility tree. After returning to the workspace, the source `鼠标里面的硅二极管坏了，导致光标分辨率降低。` and the successful result `鼠標裏面的硅二極管壞了，導致光標分辨率降低。` remained in the accessibility tree. In the minimum window, the outer view could be scrolled to the result, Copy, and Export controls. Actual window points came from the window list; captured PNG pixels include shadows and are not the measurement source.

The newly added recommended-window rows used `org.gewill.OpenCCman.SizeMatrixQA20260925`, an ad-hoc signed Debug copy of application source `40a4e33`, on macOS 27.0 / Xcode 27.0. The four newly covered Chinese minimum-window rows used the same QA app and source. `git diff --name-only 40a4e33 b3409ee -- OpenCCman OpenCCman.xcodeproj Package.resolved` was empty, so this application's source was unchanged through the later `develop` base. English / Dark minimum-window 100%, 125%, and 150% used the separate repaired Debug QA app `org.gewill.OpenCCman.ReusedWindowQA20260925` from candidate `527f3b2`; its only application-code change concerns closed-window content remounting. Both QA bundles kept the macOS sandbox and user-selected-file entitlement, removed `NSServices` from their *copies*, and passed strict ad-hoc signature verification. No production app, user file, or system language/theme setting was changed.

The old QA app later displayed a blank title-only window after language switching and restart. Those blank frames were **excluded** from the passing matrix; #57 / PR #208 records the native same-window regression, fix, real before/after screenshots, and close/reopen video. The English / Dark minimum-window states were rerun in the repaired QA app. The 125% states were confirmed through Settings selection and retained source/result accessibility values; the issue comments show 100% and 150% screenshots for each newly covered Chinese or recommended-window row and all three English / Dark minimum-window screenshots.

This matrix establishes the basic text-size, conversion, and result-retention path, not the Cartesian product of every interaction. It does **not** complete real IME marked-text behavior, full keyboard focus order, Mac VoiceOver speech order, every sheet/side-panel/import/export path at every size, macOS 12, or a final Xcode Cloud signed distribution. #191 and its parent #57 stay open for those acceptance gates.
