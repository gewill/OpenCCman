## 实际操作与结果

| 路径 | 观察 |
| --- | --- |
| 英文／浅色／150%，推荐窗口 | 左右布局转换后结果、复制和导出入口可达；改为上下布局后，原文和结果仍在，结果区域可滚动到达。此项是切换语言之前的同一隔离 App。 |
| 切换到简体中文并按提示重启 | 语言生效且 150% 偏好保留；原文保留。重启前的转换结果未作为持久化预期，重启后重新转换。 |
| 简体中文／深色／150%，推荐窗口 | 左右工作区、设置页与转换结果在实际画面中可读；原文和结果的辅助功能值分别为 `鼠标里面的硅二极管坏了，导致光标分辨率降低。` 与 `鼠標裏面的硅二極管壞了，導致光標分辨率降低。`；复制和导出按钮启用。 |
| 同窗 150%→125%→150%→100% | 每个档位在设置页的单选状态正确；回到工作区后原文与结果的辅助功能值相同，无需再次转换。100%、125%、150% 各有相同窗口、语言、外观和文本的真实截图。 |

同条件的 100%／125%／150% 截图与 18 秒无音轨、仅保留 QA 窗口的字号切换录像附在本轮 PR。录像由 `screencapture -v` 取得，再裁剪到 QA 窗口；画面展示设置切换，不能替代完整键盘、输入法或 VoiceOver 验收。截图经 Computer Use 直接取得，文件实际格式为 JPEG。媒体没有写入仓库。截图 SHA-256 分别为 `d21d7c06d3087b917e071d7ddf681b1ab2841d386388196dfaba28f1df923356`（100%）、`531e14f58fe545f2dea5be4d2b7216b36e22fde1b1e3efa81f1c5d6bab17e9e3`（125%）、`923e2ff81b296a49003849b7de6fd47b94287bcb76dbbba60b1a2d0ab8b996f0`（150%）；裁剪视频为 `8368d4b1acdc1df58e4298fb22f4ea58884b9317f61e8a13ff8f368cdfb55fc3`。

这补齐推荐窗口的简体中文／深色连续字号切换；它没有覆盖三语言、浅深色、两种窗口尺寸与所有页面的笛卡尔积，也没有验证实际输入法组合、完整键盘焦点、Mac VoiceOver 或真机签名包。#191 的矩阵尚未完成。#57 还缺**真实外接显示器断开／重连**；本机 `system_profiler SPDisplaysDataType` 只列出内建显示器，现有合成几何测试不能替代物理拔插。因此两项 Issue 均保持开放。
