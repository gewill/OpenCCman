# Mac 繁体浅色推荐窗口补验（#191 / #57）

2026-09-25 使用 `develop` `fc5a901d76e88109547397704e9037a7d9cefa05` 构建的独立 Mac Debug QA 包 `org.gewill.OpenCCman.TextSizeKeyboardQA20260925`，在 macOS 27.0 / Xcode 27.0 的内建显示器测试。该包保留沙盒和用户选定文件读写 entitlement、移除副本的 `NSServices` 并经 ad-hoc 签名校验；未运行正式签名 App。该源码至本报告起点 `develop` 的差异仅为文档。CGWindow 读回窗口为 **1024×768 pt**。

应用语言设为繁体中文、外观为浅色。同一原文先在 150% 下转换成功，之后在设置页选择 100%、125%，再从 125% 切回 150%。各档的选中状态均从实际辅助功能状态读回；返回工作区后原文 `鼠标里面的硅二极管坏了，导致光标分辨率降低。` 和结果 `鼠標裏面的硅二極管壞了，導致光標分辨率降低。` 保留，复制和导出入口启用。150% 时切换左右→上下→左右，两个编辑区的辅助功能值仍相同；没有重复执行转换。
