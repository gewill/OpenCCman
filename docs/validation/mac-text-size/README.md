# Mac 应用内文字大小验收（#191 / #57）

## 实现范围

macOS 设置页提供全应用共用的 100%／125%／150% 文字大小，默认 100%。这一偏好只影响 OpenCCman 自身，不改变系统显示设置、图标尺寸、每日额度或窗口最小宽度。SwiftUI 文本按语义字级缩放；原文与结果仍是同一原生 `NSTextView`，字号更新时保留文本、选区和可见首行，并在输入法标记文字期间延后重排。iOS/iPadOS 继续使用系统 Dynamic Type。

提供应用内入口的原因是 [Apple 对 macOS `dynamicTypeSize` 的说明](https://developer.apple.com/documentation/swiftui/environmentvalues/dynamictypesize)：用户不能在 macOS 上修改它，改变它也不会影响文字大小。此前 #57 在 macOS 27 把系统文字滑杆调到最大后，同一应用窗口截图仍逐字节相同；本次没有把该系统设置当成验收路径。
