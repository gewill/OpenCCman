| 环境 | 实际操作与观察 |
| --- | --- |
| 1024×768 pt、英语／浅色／150% | 设置单选状态为 150%；What’s New 可滚动且 Done 可用。工作区左右和上下切换后，转换产生结果；转换设置的台湾预设可选，改预设后旧结果标为使用先前配置，再转换得到新结果。原文、结果、复制和导出入口仍由辅助功能树读到。 |

| 300×412 pt、繁体中文／浅色／150% | 重启后窗口仍为 300×412 pt，原文仍在；转换后结果、复制和导出可经滚动到达。 |

当前窗口尺寸来源为截图工具 `--list-windows` 的 `300x412` 读数。应用内大字号只改变文本视觉大小，300 pt 最小宽度仍可达。观察到“文字大小”标题在窄窗 150% 下自然换行，选项保持可见；系统保存／打开面板属系统界面，不计入应用内字级覆盖。测试中的文件面板仅打开并取消，未接触用户文档内容。
