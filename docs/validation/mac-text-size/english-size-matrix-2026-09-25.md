# Mac 英语字号／窄窗矩阵补验（#191、#57；2026-09-25）

## 被测版本与隔离

- 产品源码：`40a4e33b72976bf2e42860a5d9c8fe007e110825`（当时的 `develop`，#204 合并提交）。本次只增加验收文档，没有修改产品 UI。
- macOS 27.0、Xcode 27.0（27A266a）；从该源码构建 macOS Debug App，复制为 `org.gewill.OpenCCman.SizeMatrixQA20260925` 专用包，移除复制件的 `NSServices`，以原 entitlement 进行 ad-hoc 签名并通过 `codesign --verify --deep --strict`。未运行或修改正式签名 App。
- 使用 Computer Use 操作 QA 包的设置、布局和滚动；使用窗口捕获工具截图并读回实际窗口外框。推荐窗口为 `1024×768 pt`，最小窗口为 `300×412 pt`。窄窗由专用 QA bundle 的 SwiftUI 自动恢复帧设定，重启后读回 `300×412`，未修改正式版或系统偏好。截图为物理像素并包含阴影与截屏留白，不能把图像像素当作窗口 pt 尺寸。
- 系统 VoiceOver 在本轮未开启；本轮不计入其阅读顺序验收。测试包及其偏好在记录后移除。

本轮增加了英语／浅色在两档窗口的三字号证据，以及英语／深色／150% 最小窗口。此前的简体／繁体、深色／浅色补验分散在本目录其他记录中；三语言 × 两主题 × 三字号 × 两档窗口的完整组合仍未逐项实测。真实输入法标记文字、Mac VoiceOver 阅读顺序、所有页面的键盘焦点、macOS 12 最低系统与最终签名包仍未完成。#191 继续开放，完成后再回链 #57；#57 的真实外接屏断开／重连则已另有[运行证据](https://github.com/gewill/OpenCCman/issues/57#issuecomment-5827751143)。
