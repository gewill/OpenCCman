## 当前环境边界

本次实际执行 `xcodebuild -version`（27.0 / 27A266a）、`devicectl device --help` 与 `devicectl list devices`。17 Pro Max 为 unavailable，未发现连接的实体 iPad；可见的 16 Pro 按用户先前安排留给另一项目，没有安装或操作它。已询问可用低内存 iPhone/iPad，尚待用户答复；不要把当前模拟器机型当作物理内存验证。
