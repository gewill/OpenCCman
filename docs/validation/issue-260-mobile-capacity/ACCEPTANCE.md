## 本轮环境与证据范围

本轮只在 Mac 上审计和运行工具/服务，不安装、启动或操作 iPhone、iPad 或 Simulator，不重做购买、提供方保存和 UI 验收。Xcode 27.1（27A9275）用于独立 SwiftPM 工具，实际命令、源码与哈希见本轮报告；编译成功不证明真机或最低系统通过。

2026-10-01 的设备占用与不可用状态属于历史，不能据此判断当前设备是否可用。#270 记录的 iPhone 16 Pro / TestFlight 2.2 (61) 是另一组历史局部证据；本轮没有复测，也不把旧工作区未提交的 QA smoke-test 说明纳入通过项。
