# #304：香港地域用词（`s2hkp` / `hk2sp`）

2026-11-11 实现与验证。跟踪 #301（路线图 N3）。前置决策记录在 [#304 评论](https://github.com/gewill/OpenCCman/issues/304#issuecomment-6788259781)：「香港字形 + 台湾词组」迁移到 `s2hkp`，「OpenCC 繁体 + 台湾词组」保持原样。**不代表 #304 已验收**，未验证项见文末。

## 规则

繁体输出：

| 异体字转换 | 地域用词转换 | 改动前 | 改动后 |
| --- | --- | --- | --- |
| OpenCC 标准 | 不转换 | `s2t` | 不变 |
| OpenCC 标准 | 台湾模式 | 兼容配置：OpenCC 繁体 + 台湾词组 | 不变（维护者确认保持原样） |
| 台湾标准 | 不转换／台湾模式 | `s2tw`／`s2twp` | 不变 |
| 香港标准 | 不转换 | `s2hk` | 不变 |
| 香港标准 | 台湾模式 → **香港模式** | 兼容配置：香港字形 + 台湾词组 | **`s2hkp`** |

简体输出：

| 原文标准 | 地域用词转换 | 改动前 | 改动后 |
| --- | --- | --- | --- |
| OpenCC 标准 | （不可选） | `t2s` | 不变 |
| 台湾标准 | 不转换／台湾模式 | `tw2s`／`tw2sp` | 不变 |
| 香港标准 | 不转换 | `hk2s` | 不变 |
| 香港标准 | **香港模式**（改动前不可选） | `hk2s` | **`hk2sp`** |

- **保存的值不变**：「地域用词转换」仍存为 `Taiwan Idiom`。字形或原文标准为香港时，它表示香港词组，界面显示为「香港模式」／「HongKong Idiom」。
- **老用户的输出会变化**：
  - 已保存「香港标准 + 台湾模式」的繁体设置，升级后按 `s2hkp` 输出。
  - 简体原文标准为香港、且之前保存过「台湾模式」的设置（改动前置灰、不生效），升级后按 `hk2sp` 输出。
  - 两种情况都要在 What's New 里说明。
- **OpenCC 繁体 + 台湾词组**：保持原样（2026-11-11 维护者确认）。迁到 `s2hkp` 会丢掉几乎全部台湾词组；最接近的官方配置是 `s2twp`，词组相同，只差异体字字形。以后统一为官方配置时（例如路线图 M1 改版），再一次性迁到 `s2twp`，并在 What's New 里说明。依据（OpenCC 1.4.2 命令行，旧组合用 fork 的兼容配置文件）：

  | 原文 | 旧组合 | `s2twp` | `s2hkp` |
  | --- | --- | --- | --- |
  | 鼠标里面的软件和打印机，用的是信息技术。 | 滑鼠裏面的軟體和印表機，用的是資訊科技。 | 滑鼠裡面的軟體和印表機，用的是資訊科技。 | 滑鼠裏面的軟件和打印機，用的是信息技術。 |
  | 这里的网络设置和视频文件。 | 這裏的網路設定和影片檔案。 | 這裡的網路設定和影片檔案。 | 這裏的網絡設置和視頻文件。 |
- **付费**：沿用现有规则，不新增 Pro 门槛，计次不变。

## 实现要点

| 部分 | 做法 |
| --- | --- |
| 选项 | `ChineseConverter.Options` 表达不了 `s2hkp`、`hk2sp`。App 新增只在 App 内使用的标记位 `hkIdiom`（第 11 位），与 `hkStandard` 一起表示香港词组。引擎的选项只用 0、1、5、6、10 位。 |
| 构造转换器 | 只有 `ChineseConversionService` 的转换器缓存一处构造转换器。选项含 `hkIdiom` 时改用 fork 在 #302 新增的 `ChineseConverter(configuration: .s2hkp / .hk2sp)`，引擎不会收到这个标记位。 |
| 入口 | 编辑器、服务、全局快捷键、Mac 批量与大文件、移动端大文件都传同一组选项，经同一缓存构造转换器，代码路径不变。分享扩展和 Shortcuts 只用四个预设，不涉及香港词组。 |
| 移动端任务记录 | 任务记录校验选项的位掩码，加入 `hkIdiom`，香港词组任务可以恢复。 |
| 界面 | 「地域用词转换」的选项名随字形或原文标准变化：香港显示「香港模式」，其余仍为「台湾模式」。简体的地域用词在台湾、香港来源下都可选。任务摘要同步。 |
| 文案 | 新增 `HongKong Idiom`：简体、繁体为「香港模式」，英文沿用键名（与 `HongKong Standard` 一致）。 |

  - 简体：繁体选香港标准并开启地域用词时，现在使用香港词组，不再是台湾词组，已保存的设置也会改变。转为简体时，香港原文也能转换地域用词。
