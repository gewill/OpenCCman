# #34: merged-source iOS 27 VoiceOver follow-up

The What’s New forward-reading fix documented in [the original before/after
record](README.md) was retested against `develop` merge commit
`252728318ddbbea37d938026c6ed226e83aac3d1`, after the iPad import and
Mac text-size QA merges. No application or test code was changed for this run.

Environment: Xcode 27.0 (27A266a), dedicated iPhone 18 Pro / iOS 27.0
Simulator, English, light appearance, standard content size, unsigned isolated
Debug QA bundle `org.gewill.OpenCCman.WhatsNewUITests`. The Simulator’s
VoiceOver state was **disabled before and after** both runs, as confirmed with
`xcrun devicectl device info voiceover`; the test enabled it only while
navigating. No physical device or store build was altered.

| Check | Observed result |
| --- | --- |
| `bash scripts/check-whats-new-ui.sh <dedicated-UDID> <result-dir>` | 13 tests passed, 0 failed, 0 skipped; 245.671 seconds of test execution. This includes native import/export, presentation deferral, quota/Pro and dismissal cases as implemented by the isolated QA suite. |
| Focused `xcodebuild test-without-building` of `testVoiceOverCardReadingOrder` | 1 passed, 0 failed; 18.829 seconds. Repeated the same seven forward utterances as the full run. |
| VoiceOver forward path | Heading → version → workspace card → preset card → TXT card → cancellation card → Done. Done was hittable. The API returned utterance prefixes, not entire card paragraphs. |
| State cleanup | `devicectl` reported VoiceOver disabled after both tests. |

The `.xcresult` contains actual Simulator screenshots at sheet presentation and
at the Done focus ring. A silent 12-second `simctl io recordVideo` clip of the
focused run shows navigation; the test log, rather than the video, supplies
the seven spoken-item prefixes. These artifacts are attached to the associated
PR. The full log and `.xcresult` were retained locally under
`/tmp/openccman-34-ios27-vo-20260925/`; the focused log and result are
`/tmp/openccman-34-ios27-vo-focused.log` and
`/tmp/openccman-34-ios27-vo-focused.xcresult`.

This establishes repeatable **iPhone iOS 27 Simulator forward order** in the
merged source. It does not establish full-paragraph speech, backward traversal,
other languages, iPad or Mac VoiceOver order, a physical device, real foreground
first launch, a long real conversion/import, iOS 15/macOS 12 sheet behavior, or
a signed Xcode Cloud/TestFlight build. #34 remains open for those gates; #20
tracks broader accessibility, and #16 tracks minimum-system behavior.
